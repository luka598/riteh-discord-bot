# riteh-discord-bot

A community bot used in the RITEH Discord server, serving RITEH / UNIRI-related information such as the daily menza menu and RITEH news. Not affiliated with or endorsed by the Faculty of Engineering or the University of Rijeka.

[**Invite the bot**](https://discord.com/oauth2/authorize?client_id=1298686475650601047)

## Configuration

A `.env` file with:

```
DISCORD_BOT_TOKEN=...
```
